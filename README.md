# مدير المتجر | Store Manager

تطبيق ويب متكامل لإدارة المتاجر ونقاط البيع (POS) — يعمل بالكامل داخل المتصفح مع تخزين دائم محلي (IndexedDB)، بواجهة عربية RTL وإنجليزية LTR، ووضع داكن/فاتح.

## المزايا

| الصفحة | الوظائف |
|---|---|
| لوحة التحكم | مبيعات اليوم/الشهر، عدد الفواتير، المصروفات، تكلفة البضاعة المباعة، الربح الإجمالي وصافي الربح، قيمة المخزون بالتكلفة، ديون العملاء ومستحقات الموردين، منتجات منخفضة المخزون، أحدث الفواتير، الأكثر مبيعًا، رسم بياني للمبيعات والأرباح |
| المنتجات والمخزون | إضافة/تعديل/أرشفة، باركود ورمز وتصنيف، حد التنبيه، أشرطة مخزون، تصفية (منخفض/نفد/مؤرشف)، قيمة المخزون |
| نقطة البيع | بحث سريع، سلة، تعديل كميات، خصم، عميل، دفع نقدي/شبكة/آجل، مدفوع والمتبقي، تأكيد البيع الذري (يمنع التكرار وخصم المخزون مرة واحدة) |
| فواتير المبيعات | بحث وتصفية بالحالة، تفاصيل مع COGS والربح، طباعة فاتورة، إلغاء/مرتجع يعيد المخزون ويسترد المدفوع دون حذف السجل |
| المشتريات | فاتورة شراء (مرسلة/مستلمة)، الاستلام يزيد المخزون ويحدّث متوسط التكلفة المرجّح، إلغاء يعكس الأثر |
| العملاء والديون | أرصدة محسوبة من الفواتير، دفعات جزئية/كاملة، كشف حساب، سجل مدفوعات، تنبيه تجاوز أيام السماح |
| الموردون | أرصدة ومستحقات، تسديد يوزَّع على الفواتير الأقدم، كشف حساب |
| المصروفات | تصنيف وطريقة دفع وتاريخ، قيد تلقائي في الصندوق، تأثير على صافي الربح |
| الصندوق | رصيد الصندوق والبنك، إيداع/سحب/تحويل داخلي (لا يُعد دخلًا أو مصروفًا)، حركة تفصيلية |
| التقارير | 9 تبويبات (مبيعات، أرباح، مشتريات، مصروفات، مخزون، الأكثر مبيعًا، ديون، مستحقات، صندوق) مع نطاق تاريخ وتصدير CSV وطباعة/PDF |
| الإعدادات | بيانات المتجر، العملة، اللغة، الوضع، سياسة البيع السالب، بادئات الأرقام، تصنيفات المصروفات، نسخ احتياطي/استيراد/مسح |

## القواعد المالية المطبقة

- **فصل الدخل عن التدفق النقدي**: التحصيل ليس دخلًا (الدخل سُجّل عند البيع)، والتحويل بين الصندوق والبنك ليس دخلًا ولا مصروفًا.
- **COGS بلقطة تاريخية**: تكلفة البضاعة المباعة تُحفظ داخل الفاتورة وقت البيع ولا تتغير بتغيّر سعر المنتج لاحقًا.
- **متوسط تكلفة مرجّح** عند استلام المشتريات: `(كمية×تكلفة سابقة + وارد×سعره) ÷ الكمية الجديدة`.
- **صافي الربح** = صافي المبيعات − COGS − المصروفات التشغيلية.
- **الفواتير الملغاة** لا تُحذف: تُعلَّم ملغاة، تُرجع الكميات، تُقيَّد استردادات في الصندوق، وتُستثنى من المبيعات والأرباح.
- **منع البيع المكرر**: مفتاح `clientToken` فريد في قاعدة البيانات + معاملة ذرية واحدة لكل عملية (فاتورة + مخزون + صندوق).
- **الأموال بدقة**: كل العمليات تمر عبر تمثيل السنتات مع قواعد تقريب موحدة (`src/utils/money.ts`).

## التقنيات

- React 18 + TypeScript (strict) + Vite
- Tailwind CSS (فاتح/داكن via class)
- Lucide React (أيقونات) · Recharts (رسوم بيانية)
- React Router (تنقّل) · IndexedDB عبر `idb` (تخزين دائم)
- Vitest + fake-indexeddb + jsdom (اختبارات)

## التشغيل

```bash
npm install        # تثبيت الاعتماديات
npm run dev        # خادم التطوير على http://localhost:5173
npm run build      # بناء الإنتاج في dist/
npm run preview    # معاينة نسخة الإنتاج
npm test           # 32 اختبارًا (مالية + واجهة)
```

## بيئة التشغيل والنشر

- لا يحتاج متغيرات بيئة — التخزين محلي في متصفح الجهاز (Local-first).
- بيانات كل مستخدم/جهاز مستقلة؛ للنسخ الاحتياطي: الإعدادات ← تصدير نسخة احتياطية (ملف JSON).

### النشر على Vercel

```bash
npm i -g vercel
vercel            # أو اربط المستودع من واجهة Vercel
```

- Framework Preset: **Vite** · Build Command: `npm run build` · Output Directory: `dist`
- لا يحتاج أي إعدادات إضافية (التطبيق يعتمد HashRouter ليعمل على أي مسار ثابت).

## الاختبارات

`npm test` يغطي:

1. دقة المال (جمع/طرح/ضرب/تقريب دون أخطاء فاصلة عائمة)
2. إضافة/تعديل منتج وجرد المخزون
3. بيع يخصم المخزون ويقيّد الصندوق
4. منع البيع المكرر (نفس المفتاح = نفس الفاتورة، خصم واحد)
5. منع بيع المخزون غير المتوفر (والسماح به عند التفعيل)
6. فاتورة نقدية وآجلة وجزئية
7. دفعات العميل وتحديث الرصيد وتطابق كشف الحساب
8. استلام شراء يزيد المخزون ويحدّث المتوسط المرجّح (ولو تكرر النقر)
9. إلغاء فاتورة/شراء مع عكس المخزون والحفظ التاريخي
10. المصروفات وقيودها في الصندوق
11. التحويل الداخلي بلا أثر على الربح
12. تطابق التقارير: مبيعات − COGS − مصروفات = صافي الربح
13. استمرارية البيانات بعد إعادة فتح القاعدة
14. صياغة جميع صفحات الواجهة دون أخطاء
